# ЦУТ Improvement Auto
Веб-приложение для управления небольшим автосервисом.
Проект разрабатывается как полноценная рабочая система для автоматизации ежедневной работы СТО: от записи клиента до оформления заказ-наряда, оплаты и истории ремонта.

## Основные возможности
- 👤 Клиентская база
- 🚗 Учёт автомобилей клиентов
- 📅 Запись на обслуживание
- 🔧 Заказ-наряды
- 🛠 Работы и исполнители
- 📦 Учёт использованных запчастей
- 💳 Частичные и полные оплаты
- 💰 Контроль задолженности
- 📊 Отчёты и аналитика
- 🔔 Внутренние уведомления
- 📄 Печать заказ-наряда и акта выполненных работ
- 👥 Разграничение прав пользователей
- 📝 Журнал изменений
- 🔎 Глобальный поиск
- 📶 Offline-режим
- 🔄 Синхронизация данных после восстановления соединения

## Offline-first
Приложение может продолжать работу при временном отсутствии подключения к серверу.
Локально сохраняются данные и операции создания:
- клиентов;
- автомобилей;
- записей на обслуживание.
После восстановления соединения накопленные операции автоматически синхронизируются с сервером.
Для объектов используются UUID, что позволяет создавать связанные данные offline и корректно синхронизировать их позднее.
